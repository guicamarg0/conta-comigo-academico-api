# Conta Comigo — cofre acadêmico

Sistema multiusuário e multiunidade para preparar orçamentos, gerar contratos e organizar a execução de serviços. O orçamento é o ponto de partida do fluxo comercial.

Este cofre descreve a implementação entregue nesta cópia acadêmica. Decisões históricas, propostas futuras e procedimentos do ambiente original não estão incluídos.

- [[Regras de negocio]]: atores, permissões, cadastros, documentos e serviços.
- [[Arquitetura]]: componentes, segurança, isolamento por unidade, banco, PDFs e execução local.

Para executar, consulte o README da API. Abra esta pasta inteira no Obsidian; não é necessário instalar plugins.
